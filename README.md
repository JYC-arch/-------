# 個案報告｜學生個人作業

依台灣護理學會「個案報告審查評分表」（民國 112 年 10 月 24 日修訂）製作的繁體中文網頁作業。這是課堂練習工具，並非台灣護理學會官方系統。

## 使用方式

1. 開啟網頁，填寫學生姓名、學號及報告題目。
2. 依九個章節撰寫個案報告，可展開各章節查看評分規準。
3. 摘要不得超過 500 字；頁面以不含空白與換行的字元數協助檢查。
4. 完成最後檢查後，選擇「下載作業（.md）」或「列印 / 另存 PDF」，並依教師指定管道繳交。

瀏覽器會嘗試自動保存草稿。建議定期「匯出可續寫草稿」（JSON），可在其他裝置匯入。瀏覽器資料被清除、使用無痕模式、更換網址或裝置後，原草稿可能無法還原。

## 評分架構

| 項目 | 分數 |
| --- | ---: |
| 文字敘述（全篇） | 5 |
| 摘要 | 5 |
| 前言 | 5 |
| 文獻查證 | 15 |
| 護理評估（含個案簡介） | 15 |
| 問題確立 | 10 |
| 護理措施 | 20 |
| 結果評值 | 10 |
| 討論與結論 | 10 |
| 參考資料 | 5 |
| **總計** | **100** |

原表為 60 分（含）以上通過、59 分（含）以下不通過，並提醒是否通過應視全篇能否凸顯護理過程決定。本頁不自動評分或判定通過，實際課程成績由教師決定。

## 發布至 GitHub Pages

將此資料夾內容（index.html、style.css、app.js、README.md）放在指定儲存庫根目錄。於 GitHub 儲存庫 Settings → Pages 中，選擇 Deploy from a branch，並選擇實際使用的分支及 `/ (root)`，儲存後等候發布。

本專案是靜態網站，無須安裝套件或建置，可直接以瀏覽器開啟 index.html。也可在此資料夾執行 `python -m http.server 8765`，瀏覽 `http://localhost:8765`。

## 資料處理

網站不含伺服器、登入或集中收件功能，不會把填寫內容傳給教師或儲存至 GitHub。姓名、學號與作業內容留在目前瀏覽器及學生下載的檔案；實際繳交須另行操作。網站未載入外部字型、分析工具或第三方程式。

請以代稱描述個案，移除可識別病人的資料。GitHub 儲存庫僅放空白作業程式，勿上傳學生已填寫作業或草稿。本專案未附原始 PDF，評分規準依使用者提供之 112 年版整理。
