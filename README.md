## 個案報告審查練習（個人報告）

採用台灣護理學會個案報告審查評分表（中華民國112年10月24日修訂）

學生自行選找一篇已發表的個案報告，閱讀後依台灣護理學會「個案報告審查評分表」（112 年 10 月 24 日修訂）填寫評語與評分。

## 作業流程

1. 填寫學生姓名、學號、受評文章題名與完整出處。
2. 依十項審查項目，給予每個細項分數，並為各大項填寫評語；可引用頁碼或段落說明評分依據。
3. 系統加總各項得分，滿分 100 分。分數可採 0.5 分，範圍不得超過各細項上限。
4. 填寫審查總評與學生審查決議。
5. 下載 Markdown 作業或列印另存 PDF，依教師指定管道繳交。

摘要 500 字內是對受評文章的審查規準，並非對學生評語的字數限制。此作業不要求學生另寫一篇個案報告。

## 評分架構

文字敘述 5、摘要 5、前言 5、文獻查證 15、護理評估 15、問題確立 10、護理措施 20、結果評值 10、討論與結論 10、參考資料 5，合計 100 分。

原表參考為 60 分（含）以上通過、59 分（含）以下不通過，並強調應視全篇是否凸顯護理過程判斷。審查決議由學生填寫；系統僅提示分數與決議差異，不代替判斷。此處分數為學生對文章的審查練習分數，並非教師對學生作業的評分。

## 網站與資料

正式網頁：https://jyc-arch.github.io/nursing-report-writing-assignments/

靜態網頁，直接開啟 index.html 即可使用。可在 GitHub Pages 設定 main 分支與根目錄發布。各項目使用不同柔和色系。

草稿保存在目前瀏覽器，可匯出 JSON 備份或在其他裝置匯入。本頁無伺服器收件功能，不會將學生填寫內容傳送至 GitHub 或教師。請勿將已填寫的學生作業或文章全文上傳到公開儲存庫。

審查草稿採用獨立格式，避免將舊版個案報告撰寫草稿誤當評語。此為課堂練習工具，非台灣護理學會官方系統。
